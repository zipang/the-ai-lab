# Technical Writing (@the-ai-lab/recipes/technical-writing)

This recipe contains one skill. It writes and reviews technical prose in
ASD-STE100 Simplified Technical English (STE). It removes the
"AI slop" from agent-written text and makes documentation clear and
unambiguous.

ASD-STE100 Simplified Technical English (STE for short) is a controlled 
natural language and an international standard to write technical documentation.
It enforces a restricted vocabulary and strict writing rules.

The skill applies the same discipline to the prose the agent writes. It
enforces active voice, plain verbs, and consistent naming. Use STE for
technical prose such as READMEs, AGENTS.md instructions, docs..

## Usage

Ask the agent to write or review text with the `technical-writing` skill:

- "Write a README for this module in STE."
- "Review these installation instructions with the Technical Writing skill."
- "Rewrite AGENTS.md instructions using the `technical-writing` skill."
