# Local MCP Servers

This directory contains templates and instructions for creating *local* MCP servers using **Bun** and **TypeScript** or **Rust**.

Local MCP servers are ideal for keeping private data private and ensuring fast, private interactions with your local tools and filesystem.

## Contents

- [Bun template for a local MCP server](./bun-template/README.md)
- [Blazing-fast Rust MCP server for filesystem operations](./rust-mcp-filesystem/README.md)
- [MCP Inspector](./mcp-inspector/README.md): The official debug tool for testing MCP servers.
- `mcp-image-studio/`: Multi-provider AI image generation MCP server (source code, no separate guide yet).
